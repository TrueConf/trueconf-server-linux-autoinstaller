Скрипт определяет ОС, подготавливает систему и устанавливает TrueConf Server
(инсталлятор TrueConf Server для Linux) с сайта TrueConf (`trueconf.com`;
пакеты для российских дистрибутивов скачиваются с `download.trueconf.ru`).

## Поддерживаемые ОС (x86_64)

| ОС | Версии | Пакет |
|---|---|---|
| Debian | 11, 12, 13 | .deb |
| CentOS Stream | 9 | .rpm |
| Astra Linux SE | 1.7, 1.8 | .deb |
| РЕД ОС | 7.3, 8 | .rpm |
| Альт Сервер | 10, 10.2 (c10f2), 11 | .rpm |

## Запуск

> [!IMPORTANT]
> Для установки требуются права администратора (root).

> [!NOTE]
> Привилегированные операции (пакетный менеджер, перезапуск служб, запись в
> `/etc` и `/opt`) выполняются через `sudo`, поэтому скрипт можно запускать от
> обычного пользователя — в том числе через pipe (`curl ... | bash`).

```sh
curl -LsSf https://trueconf.com/go/install.sh | bash
```

или запустите с аргументами:

```sh
# 1.
curl -LsSf https://trueconf.com/go/install.sh -o install.sh

# 2.
bash install.sh [--admin-users=user1,user2] [--yes] [--port=NNNN] [--file=FILE] [--skip-update] [--allow-env-hooks] [--help] [--version] 
```

`sudo` не обязателен: скрипт сам запрашивает его для привилегированных
операций, либо можно сразу запустить ту же команду через `sudo`.

| Параметр | Назначение |
|---|---|
| `--admin-users=a,b` | Пользователи ОС с доступом к панели управления (передаётся через `TCADMINS_USERS`). Валидация формата: имена через запятую, до 32 символов `[A-Za-z0-9_.-]`, пробелы вокруг имён игнорируются |
| `--yes` | Неинтерактивный режим: вопросы не задаются. Если порт занят (в том числе указанный через `--port`), автоматически берётся первый свободный порт начиная с 8888 |
| `--port=NNNN` | Явно указать порт панели управления (только цифры 1–65535; если занят — повторный запрос, а в режиме `--yes` берётся первый свободный начиная с 8888) |
| `--file=ФАЙЛ` | Установка из локального файла (`.deb`/`.rpm`) без скачивания; расширение должно соответствовать ОС. Относительный путь автоматически превращается в абсолютный |
| `--skip-update` | Пропустить обновление системных пакетов (`apt-get upgrade` / `dnf update`); `curl` при необходимости ставится отдельно |
| `--allow-env-hooks` | Учитывать переменные окружения `TC_*`/`DL_DIR` (тестовые хуки; без этого параметра игнорируются) |
| `-h, --help` | Справка (язык зависит от локали ОС) |
| `-v, --version` | Показать версию скрипта |

## Что делает скрипт

1. Выполняет привилегированные операции через `sudo` (работает и от root,
   и от обычного пользователя с доступом к sudo).
2. Определяет ОС по `/etc/os-release`; неподдерживаемая ОС или архитектура
   (не x86_64) — сообщение и выход.
3. Проверяет, что пользователя `trueconf` нет (установщик создаёт его сам)
   и что TrueConf Server ещё не установлен.
4. Проверяет и правит репозитории: отключает локальные медиа-источники
   (CD/DVD) и делает активными необходимые дистрибутивные репозитории.
   На Debian основная suite обнаруженного выпуска должна быть активна —
   закомментированная раскомментируется, иначе ошибка. На Astra и Альт нужен
   активный источник `deb`/`rpm http(s)`. На CentOS и РЕД ОС отключённые
   дистрибутивные репозитории (`baseos`/`appstream`, `base`/`updates`)
   включаются прямо в файлах `.repo` (`enabled=1`), даже если какой-то другой
   репозиторий уже включён; требуется хотя бы один включённый http(s)
   репозиторий. На CentOS дополнительно устанавливается EPEL (нужен для
   зависимостей TCSL).
5. Если не указан `--skip-update`, обновляет системные пакеты и ставит `curl`.
   На Debian/Astra — `gnupg2`, на Альт — `gnupg`. Для Debian — безопасный
   `upgrade`; для Astra — `upgrade --enable-upgrade` (apt на Astra блокирует
   обычный `upgrade`, не `dist-upgrade`). Если `curl` всё ещё отсутствует
   (например, при `--skip-update`), он ставится отдельно перед скачиванием.
6. Выбирает порт панели управления. Только цифры, диапазон 1–65535,
   проверка занятости через `ss -tlnn`/`netstat -tlnn` (числовой вывод; если
   утилиты нет — ошибка). Если выбранный порт занят — повторный запрос. В
   режиме `--yes` берётся первый свободный порт начиная с 8888; при
   недоступном вводе (EOF, cron/CI) тоже берётся первый свободный начиная
   с 8888.
7. Скачивает инсталлятор TrueConf Server для Linux с
   `trueconf.com/download/server/linux` (для российских дистрибутивов —
   Astra, РЕД ОС, Альт — с `download.trueconf.ru/download/server/linux`).
   Загрузка идёт в приватный временный каталог, созданный через `mktemp -d`
   (режим 0700). Переопределение `DL_DIR` учитывается только с
   `--allow-env-hooks` и отклоняется, если путь — симлинк, не принадлежит
   текущему пользователю или родитель пути — симлинк. Устойчивый curl:
   только IPv4, докачка через `-C -`, повторы при ошибках (без
   `--retry-all-errors` — нет в curl < 7.71 на Astra/РЕД), отсечка соединений
   медленнее 1 КБ/с в течение 30 с. Если сервер вернул HTML-страницу вместо
   пакета, скачивание считается ошибкой. Временный каталог удаляется после
   установки, в том числе при сбое.
8. Устанавливает TrueConf Server для Linux; администраторы панели — через
   `TCADMINS_USERS`. Установка пакета идёт неинтерактивно
   (`DEBIAN_FRONTEND=noninteractive` для apt), поэтому вопросы debconf не
   блокируют cron/CI.
9. Если выбранный порт ≠ 80 — применяет его после установки
   (`/opt/trueconf/server/etc/webmanager/listen.conf` и
   `/opt/trueconf/server/etc/manager/manager.toml`) и перезапускает службы.
   Заменяются только директивы, слушающие на текущем порту (80): сохраняются
   адрес/опции (`Listen 80` → `Listen 9000`, `Listen 0.0.0.0:80` →
   `Listen 0.0.0.0:9000`, `Listen 443 ssl` не трогается) и схема connection
   (`http`/`https`/`ws`). При отсутствии целевой директивы или
   конфигурационного файла — ошибка вместо тихого пропуска или дописывания
   дублей (невалидный TOML).
10. Выводит URL панели, напоминание о регистрации (Free: порт 4310/TCP
    до `reg.trueconf.com`) и напоминание о настройке HTTPS.
